# Mustick - In TU/e 2008

This is a reimplimentation for an old student project, "Mustick" in 2008 of TU/e.

<br>

## Hardware

- Arduino Nano RP2040 Connect
- Seeed Studio Lipo Rider Plus
- Lipo battery
- Raspberry Pi (I use RPi 4 here)

<br>

## Programming

- **Arduino IDE**
  - Library：[**DFRobotDFPlayerMini**](https://github.com/DFRobot/DFRobotDFPlayerMini)
- **Processing**
  - Library: [OSCP5](https://github.com/sojamo/oscp5)
- **Python**
  - Library: [bleak](https://github.com/hbldh/bleak), [pythonosc](https://github.com/attwad/python-osc)

<br>

## Technique

- BLE

<br>

## Wiring

| Arduino Nano RP2040 Connect |  Lipo Rider Plus  | Lipo battery |
| :------: | :-----: | :-----: |
|   Vin    |   5V   |  Red |
|   Gnd    |   Gnd   | Black |
